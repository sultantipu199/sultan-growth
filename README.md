## 🚦 Quick Start & Local Preview

Run locally using Python's built-in HTTP server:

```bash
# Clone the repository
git clone https://github.com/sultantipu199/sultan-growth.git
cd sultan-growth

# Launch local server on port 3000
python -m http.server 3000
```

Open [http://localhost:3000](http://localhost:3000) in any modern browser.
